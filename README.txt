NUTRIVA — tienda demo en HTML, CSS y JavaScript

CÓMO ABRIR
1. Descarga y descomprime el ZIP.
2. Abre index.html con tu navegador.
3. Para editar el contenido:
   - index.html: estructura y textos principales
   - styles.css: colores, tamaños y diseño
   - script.js: productos, buscador, carrito y asistente

IMPORTANTE
Esta versión es una demostración local. El catálogo, los precios y las descripciones son de ejemplo.
El pedido no procesa pagos reales. Para vender online debes integrar una plataforma de comercio electrónico,
una pasarela de pago segura, inventario, envíos y las páginas legales correspondientes.
